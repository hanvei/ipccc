ABOUT THIS TOOL
使用说明
1. 导入：选择未加密的 XML plist 文件。文件仅由当前浏览器读取。
2. 编辑：在字段列表里改值。工具会保留未修改的字段，并标记每个改动。
3. 检查：打开“预览修改差异”，确认前后内容。
4. 导出：保存为新的 plist 文件；不会安装到 iPhone。
当前版本不支持 .ipcc 压缩包、二进制 plist、设备连接、系统目录写入或网络锁定操作。
